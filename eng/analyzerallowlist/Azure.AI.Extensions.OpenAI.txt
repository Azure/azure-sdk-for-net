# OPENAI001 / OPENAICUA001 are the [Experimental] markers on the OpenAI SDK types this
# library extends. The OpenAIExperimentalVisitor in the codegen plugin (sdk/ai/codegen)
# propagates these markers onto the generated public surface, so downstream consumers are
# correctly warned per-symbol. These assembly-wide entries are still required because the

# they cannot be narrowed via scoped (point) suppression. Hand-written custom extension
# code also relies on these until it is individually audited and attributed.

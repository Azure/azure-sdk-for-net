# These four names are the core vocabulary of the provisioning object model and all shipped
# in the GA 1.0.0 public API, so renaming them would be breaking. 'Infrastructure' and
# 'Provisionable' are the root abstractions authors derive from, and 'Subscription' and
# 'Tenant' name the Azure scopes they deploy into; the qualifying namespaces
# (Azure.Provisioning, .Primitives, .Resources) already distinguish them from same-named
# types elsewhere.

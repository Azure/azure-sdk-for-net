# Azure.AI.AgentServer.Responses approved analyzer suppressions.
# See eng/analyzerallowlist/README.md for the file format and review policy.

# AZC0100 fires on awaits that omit ConfigureAwait(false). This package is a
# server-side hosting library that runs on the ASP.NET Core request pipeline,
# where there is no UI / SynchronizationContext to capture; ConfigureAwait(false)
# is at best unnecessary and at worst incorrect for hosted-service / middleware
# scenarios. The Azure.Core guideline that AZC0100 enforces is targeted at
# client libraries called from arbitrary contexts and does not apply here.
# Same exemption as the parent Azure.AI.AgentServer.Core; see AGENTS.md §0.VI.
nowarn:AZC0100

# AZC0004 fires on async APIs that lack a corresponding sync variant. This
# package only exposes async APIs by design — its surface area is the agent
# Responses-protocol surface on top of AgentServer.Core, where sync variants
# would either deadlock under ASP.NET Core or duplicate code without value.
# Same exemption as the parent Azure.AI.AgentServer.Core (and AMQP-based SDKs).
nowarn:AZC0004

# AAIP002 is the [Experimental] marker stamped by the OpenAIExperimentalVisitor in the
# codegen plugin (sdk/ai/codegen) onto surface that exposes OpenAI-experimental types.
# Now that this package consumes OpenAI.Responses models through Azure.AI.Extensions.OpenAI
# instead of re-declaring them, that marker covers most of the generated surface and the
# hand-written hosting code that builds on it. The diagnostic exists so external consumers
# explicitly acknowledge experimental usage; internal use across the assembly is by design.
# File-scoped pragmas would be wiped on every codegen regen of the affected generated files.
nowarn:AAIP002

# OPENAI001 marks the OpenAI.Responses surface this package is built on. It cannot be
# suppressed with attributes alone: the System.ClientModel model-reader source generator
# emits a reference to OpenAI.OpenAIContext into AzureAIAgentServerResponsesContext.g.cs,
# which we cannot annotate and which is regenerated on every build. The public surface
# remains gated behind the package's own AAIP002 experimental marker.
nowarn:OPENAI001

# OPENAICUA001 marks the OpenAI computer-use surface (ComputerCallAction and friends).
# The spec models the computer-use tool, so these types appear in generated serialization
# code for the same source-generated reasons described for OPENAI001 above.
nowarn:OPENAICUA001

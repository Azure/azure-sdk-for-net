# Release History

## 1.0.0-beta.1 (Unreleased)

### Features Added

- Initial preview release of the Azure.ResourceManager.EdgeOperator library, generated from the `Microsoft.EdgeOperator` `2026-06-01-preview` API.
- Added `BillingConfigurationResource` with support for getting and create-or-replace (PUT) on the singleton `default` billing configuration.
- Added `BillingConfigurationSnapshotResource` and `BillingConfigurationSnapshotCollection` for reading immutable historical snapshots of the billing configuration.

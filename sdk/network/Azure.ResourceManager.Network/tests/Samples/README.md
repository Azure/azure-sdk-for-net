Source files in this directory are written as tests from which samples are extracted.
They are not intended to be viewed directly and help ensure our samples compile and work correctly.
See our [list of samples](https://github.com/Azure/azure-sdk-for-net/tree/main/sdk/network/Azure.ResourceManager.Network/samples) for more explanation about how to use this client library.

Files headed `Maintained sample originally generated by AutoRest` are now maintained
by hand. Their original 2025-05-01 example references document their provenance; the
TypeSpec generator does not regenerate these files. Keep their scenarios intact
and use the preferred SDK members when updating them.

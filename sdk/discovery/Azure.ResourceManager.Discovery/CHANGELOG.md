## 1.0.0-beta.1 (2026-08-03)

Initial beta release of the Azure Resource Manager Discovery client library for .NET. This library targets the `Microsoft.Discovery` resource provider, API version `2026-06-01`.

### Features Added

- Management of Discovery resources: workspaces, projects, bookshelves, supercomputers, node pools, chat model deployments, tools, storage assets, and storage containers.
- Private endpoint connection and private link resource support for workspaces and bookshelves.

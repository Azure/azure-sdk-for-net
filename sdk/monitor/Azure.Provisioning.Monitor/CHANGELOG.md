# Release History

## 1.0.0-beta.2 (Unreleased)

### Features Added

- Added support for diagnostic setting categories, service diagnostic settings, tenant action groups, VM Insights onboarding status, and additional private link resources.

### Breaking Changes

- Removed Monitor workspace and pipeline group resources because they are not part of the Microsoft.Insights TypeSpec project.
- Removed beta-only compatibility aliases, legacy API-version constants, and the classic Alert Rule API that are not generated by the current TypeSpec specification.

### Bugs Fixed

### Other Changes

- Migrated the library from the reflection-based provisioning generator to the TypeSpec provisioning emitter.

## 1.0.0-beta.1 (2026-04-07)

### Features Added

- Initial beta release of new Azure.Provisioning.Monitor.

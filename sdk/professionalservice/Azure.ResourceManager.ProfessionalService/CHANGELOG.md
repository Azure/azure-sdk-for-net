# Release History

## 1.0.0-beta.1 (2026-11-30)

### Features Added

- Initial beta release of `Azure.ResourceManager.ProfessionalService` targeting API version `2026-05-01`.
- Added support for managing Azure Professional Service resources (`ProfessionalServiceResource`, `ProfessionalServiceCollection`, `ProfessionalServiceData`), including create, get, update, delete, and list operations.
- Added support for validating proposed Professional Service purchases and resource updates.
- Added support for checking Professional Service resource name availability.
- Added support for unsubscribing from a Professional Service subscription.
